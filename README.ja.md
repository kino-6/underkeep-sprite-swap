# Underkeep Sprite Swap

[English](README.md)

**Underkeep**（Steam）のキャラの顔などの絵を、自分の画像に差し替えるための手元用の道具です。
全部の絵をブラウザで一覧し、画像を落とし、大きさに合わせて切り抜いてゲームに書き込みます。元の atlas は自動で控えます。

> 非公式のファン製ツールです。Underkeep の開発元・販売元とは関係ありません。
> この repo にゲームの画像は含みません。インストール先から取り出した画像は、すべてお使いの PC の中に留まります。

## できること

- 約 3,800 枚の絵を一覧できます。主人公の顔、仲間、敵、人物などです
- 画像はドラッグ＆ドロップ、貼り付け（Ctrl+V）、ファイル選択で読み込めます
- 絵の大きさに合わせて自動で切り抜き・縮小します。ドラッグで位置を、ホイールで拡大率を変えられ、「全体を収める」「枠いっぱいにする」も選べます
- ドット絵向けに、滑らかにせず縮めることもできます
- 主人公の顔には瞬き用の絵があります。既定で一緒に差し替えます
- まず下書きに置き、**ゲームに反映** を押したときだけゲームに書き込みます
- 控えは自動で取ります。1 枚ずつでも、全部まとめてでも元に戻せます
- Steam の整合性確認やアップデートで元に戻ったことを検出し、ボタン 1 つで反映し直せます
- 画面は日本語と英語に対応しています
- インストールは不要です。Windows 標準の PowerShell 5.1 以上とブラウザで動きます

## 使い方

1. この repo をダウンロード（Code → Download ZIP）して、好きな場所に展開します。
2. **`uksprite-web.bat`** をダブルクリックします。ブラウザで `http://localhost:18093/` が開きます。
3. 顔をクリックして画像を選ぶか、顔の上に画像を落とします。切り抜きを調整して **決定** を押します。
4. **ゲームに反映** を押します。ゲームを起動中なら再起動してください。

止めるときは、黒い画面で Ctrl+C を押します。

枠の色は状態を表します。

| 枠 | 意味 |
|---|---|
| 橙の点線 | 下書き。まだゲームに入っていない |
| 緑 | ゲームに反映済み |
| 赤 | 反映したが、Steam の検証や更新で外れた。**ゲームに反映** で戻せる |

## 控えと安全のための仕組み

- atlas を初めて書き換える前に、元の atlas をスクリプトと同じ場所の `backup\` に控えます。
- ゲームに反映した絵は `applied\` にも取っておきます。Steam がファイルを戻した後でも反映し直せます。
- 起動時に、ゲームの atlas と記録を照らし合わせます。
  - **元に戻っていた**（控えと同じ）場合は、該当の絵を赤くして反映し直せるようにします。
  - **ゲームの更新で変わっていた**（どちらとも違う）場合は、控えを新しい atlas に取り替えます。古い控えで戻すと更新を壊すためです。
- **全部元に戻す** で元の画素をすべて戻します。戻すものがなくなったら控えも消します。
- Steam の「ゲームファイルの整合性を確認」を使えば、いつでも手つかずの状態に戻せます。

変わるのはお使いの PC のファイルだけです。

## コマンドで使う

```powershell
.\uksprite.ps1 list '^face_3'               # 名前・atlas・位置・大きさ・状態
.\uksprite.ps1 export '^face_300' .\work    # .\work\face_300.png と face_300_blink.png ができる
# 大きさを変えずに PNG を描き替える
.\uksprite.ps1 import .\work                # 下書きに置く
.\uksprite.ps1 commit                       # ゲームに反映する
.\uksprite.ps1 restore                      # 全部元に戻す（名前の正規表現で絞り込める）
```

実行ポリシーで止まるときは `powershell -ExecutionPolicy Bypass -File .\uksprite.ps1 ...` で起動します。

### オプション

| オプション | 既定 | |
|---|---|---|
| `-GameDir` | `C:\Program Files (x86)\Steam\steamapps\common\Underkeep` | 別の場所に入れたときのゲームフォルダ |
| `-Port`（web のみ） | `18093` | 使うポート。`localhost` からしかつながらない |
| `-NoOpen`（web のみ） | | ブラウザを開かない |
| `-Lang` | Windows の表示言語 | 黒い画面の表示を `en` か `ja` にする。web 画面はブラウザに合わせ、画面上でも切り替えられる |

## 仕組み

Underkeep の絵は、普通の PNG の atlas（`base\atlas*.atlas_N.texture.png`、2048×2048）に詰めてあります。
各絵がどの atlas のどの範囲にあるかは `base\_sprite.db` に書かれています。この道具はその db を読み、atlas との間で画素を写します。db は書き換えないので、差し替える絵は元と同じ大きさにする必要があります。編集画面がその大きさに合わせます。

db の形式は [README.md](README.md#how-it-works) に書いてあります。
